# Workflow

- Read a file before editing it. Look for existing code to reuse before writing new code.
- When a request is ambiguous, ask instead of guessing. Use the `grill` skill if many decisions are open.
- Before changing 3 or more files, write a short plan with the `plan` skill.
- For bugs, find the root cause first with the `debug` skill. Do not patch symptoms.
- Verify the work (tests, typecheck, running it) before saying it is done.
