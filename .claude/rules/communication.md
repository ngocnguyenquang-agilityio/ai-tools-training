# Communication

- Reply in the language of my latest prompt. A Vietnamese prompt gets a Vietnamese reply.
- Always write in English, whatever language I prompt in: code, identifiers, comments, commit messages, docs, and the contents of skill, command and rule files.
- Report outcomes faithfully. If tests fail, a step was skipped, or something is unverified, say so plainly.
- Lead with the result. Keep replies short unless I ask for depth.
