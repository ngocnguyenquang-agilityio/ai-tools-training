## Goal

Add Playwright end-to-end tests that check the real server-rendered page in a browser.

## Tasks

- [ ] Run `pnpm create playwright`. Use TypeScript, put the tests in `e2e/`, and don't add a CI workflow for now (the repo is on GitLab, so CI would be a GitLab CI pipeline, not the GitHub Actions file the installer offers).
- [ ] `playwright.config.ts`:
  - [ ] `webServer: { command: 'pnpm build && pnpm start', url: 'http://localhost:3000', reuseExistingServer: !process.env.CI }`
  - [ ] `baseURL: 'http://localhost:3000'`
  - [ ] Start with the Chromium project only.
- [ ] Specs in `e2e/news.spec.ts`:
  - [ ] Home shows a list with at least one story link.
  - [ ] Clicking the "New" tab changes the URL to `feed=new` and marks the tab active.
  - [ ] Next/Prev pagination updates `page` in the URL.
  - [ ] An invalid query (`/?feed=foo&page=-1`) falls back to Top, page 1.
- [ ] Add the script `test:e2e` (`playwright test`).
- [ ] Add `test-results/`, `playwright-report/` and `playwright/.cache/` to `.gitignore`.
- [ ] Make sure Jest ignores `e2e/`.

## Acceptance criteria

- `pnpm test:e2e` passes locally.
- `pnpm test` (Jest) does not pick up the Playwright specs.

## Notes

The tests hit the live HN API, so assert on structure (counts, URLs, active tab) rather than on specific story titles.
